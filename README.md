# Kirushnavy Yogathas — Portfolio

Personal portfolio site showcasing projects, skills, and background as an IT undergraduate exploring data science, AI, and practical software development.

🔗 **Live site:** https://abyyogathas-1129.github.io/Portfolio/

## About

Built to highlight selected projects with honest, verified details — each project card states exactly what was built, the individual contribution (for group work), and links to the source repository.

## Tech stack

- React + TypeScript
- Vite
- Plain CSS (custom design system, no framework)

## Featured projects

- **Academic Study Assistant** — FastAPI + LangChain + Groq study chatbot with MongoDB-backed history
- **Weather App** — Native Android weather UI (Kotlin)
- **Git & GitHub Assignment** — Version control practice exercise

See the live site for full details and links to each project's repository.

## Running locally

```bash
npm install
npm run dev
```
